## 💎 ¿Qué es VIVIGEOSILHA?

**No es un nombre inventado — fue descubierto.**

Nace del interior de una **geoda de amatista**: roca común por fuera, un reino de cristales violetas por dentro. Formada en la tierra durante millones de años, guardando luz que hoy brilla como **VIVIGEOSILHA**.
